# 길드 연금 작업대 GUI 작업 기록

## 현재 상태

- 사용자가 제공한 시안을 바탕으로 GUI 배경 이미지를 준비했다.
- 새로 설치하는 제작대는 바닥 가로 2칸, 높이 2칸(깊이 1칸)의 테스트용 모델이다. 최종 외형은 시안 1을 기준으로 추후 제작한다.
- 기존 버전에서 설치한 1블록 작업대는 그대로 유지한다. 회수해 다시 설치하면 2×2 크기를 사용한다.
- 새 작업대는 공간이 막혀 있으면 설치하지 않고, 네 부분 중 어느 부분을 부숴도 하나로 회수한다.
- 작업대 컨트롤러에 아이템 저장 6칸과 최대 4,000 mB 물 저장을 구현했다. GUI 메뉴와 포션 제작 기능은 아직 구현하지 않았다.
- 배경에 그려진 칸과 버튼은 아직 조작할 수 없으며, 실제 게임에서 테스트하지 않았다.
- 물 양동이로 작업대 어느 부분이든 우클릭하면 빈 공간이 충분할 때 1,000 mB를 충전한다. 생존 모드는 빈 양동이를 돌려주고 크리에이티브 모드는 물 양동이를 유지한다.
- 빈손 우클릭으로 현재 물 저장량을 확인한다. 인벤토리 6칸은 GUI 구현 전까지 게임에서 직접 조작할 수 없다.
- 작업대가 파괴되면 아이템은 한 번씩 떨어지고 저장된 물은 사라진다. 주변 클라이언트에는 물 저장량만 동기화한다.

## 확정된 사항

- 물탱크 최대 용량은 **4,000 mB**다.
- 재료 입력 슬롯은 약초 3개, 촉매 1개, 빈 유리병 1개이며 결과 슬롯은 1개다.
- 플레이어 인벤토리 27칸과 핫바 9칸을 실제 메뉴 슬롯으로 연결한다.
- 물과 빈 유리병은 각각 별도의 재료로 처리한다.
- 레시피와 등급에 따라 필요한 아이템과 개수를 보여 준다.
- 저장량, 포션 미리보기와 실제 결과는 서버 데이터와 구분해 표시한다.

## 디자인 리소스

- 배경: `src/main/resources/assets/farmrpgjobs/textures/gui/guild_alchemy_background.png`
- 크기: 1536 × 1024 픽셀
- 그림 속 고정된 재료와 물의 양은 제거했다. 글자, 실제 아이템, 인벤토리 36칸, 물 높이, 선택 상태는 GUI 구현 단계에서 별도로 표시해야 한다.
- 배경 자체에 미리 선택된 레시피가 없어야 한다.
- 36칸에 맞게 아래 공간을 넓혔다. 화면 해상도와 게임의 GUI 크기에 맞는 배치 및 마우스 좌표는 추후 실제 게임에서 검증해야 한다.

## 추후 결정·구현 사항

- 물 양동이 충전은 바닐라 양동이 용량인 1,000 mB를 사용한다. 포션 제작당 사용량 250 mB는 기존 제안값이며 아직 적용하거나 최종 확정하지 않았다.
- 이후 GUI의 물 충전 버튼을 서버 검증에 연결한다.
- 최종 시안에 맞춰 제작대의 세부 모델과 텍스처를 개선한다. 현재 2×2 모델은 테스트용이다.
- 달빛의 물약은 현재 사용할 수 없으므로 제작 허용 여부를 정하고 상태를 안내한다.
- GUI와 제작 로직을 순서대로 구현하고 각 단계에서 테스트한다.
