# 길드 연금 작업대 GUI 작업 기록

## 현재 상태

- 사용자가 제공한 시안을 바탕으로 GUI 배경 이미지를 준비했다.
- 제작대 블록, GUI 메뉴, 인벤토리, 물탱크와 포션 제작 기능은 아직 구현하지 않았다.
- 배경에 그려진 칸과 버튼은 아직 조작할 수 없으며, 실제 게임에서 테스트하지 않았다.

## 확정된 사항

- 물탱크 최대 용량은 **4,000 mB**다.
- 재료 입력 슬롯은 약초 3개, 촉매 1개, 빈 유리병 1개이며 결과 슬롯은 1개다.
- 플레이어 인벤토리 27칸과 핫바 9칸을 실제 메뉴 슬롯으로 연결한다.
- 물과 빈 유리병은 각각 별도의 재료로 처리한다.
- 레시피와 등급에 따라 필요한 아이템과 개수를 보여 준다.
- 저장량, 포션 미리보기와 실제 결과는 서버 데이터와 구분해 표시한다.

## 디자인 리소스

- 배경: `src/main/resources/assets/farmrpgjobs/textures/gui/guild_alchemy_background.png`
- 크기: 1536 × 1024 픽셀
- 그림 속 고정된 재료와 물의 양은 제거했다. 글자, 실제 아이템, 인벤토리 36칸, 물 높이, 선택 상태는 GUI 구현 단계에서 별도로 표시해야 한다.
- 배경 자체에 미리 선택된 레시피가 없어야 한다.
- 36칸에 맞게 아래 공간을 넓혔다. 화면 해상도와 게임의 GUI 크기에 맞는 배치 및 마우스 좌표는 추후 실제 게임에서 검증해야 한다.

## 추후 결정·구현 사항

- 물 양동이 1개당 충전량 1,000 mB와 제작당 사용량 250 mB는 기존 제안값이며, 이 문서에서 최종 확정하지 않는다.
- 물통 충전 조작과 크리에이티브 모드 처리 방식을 정한다.
- 월드에 설치할 제작대의 크기와 모델을 정한다.
- 달빛의 물약은 현재 사용할 수 없으므로 제작 허용 여부를 정하고 상태를 안내한다.
- 블록, 저장 기능, GUI, 제작 로직을 순서대로 구현하고 각 단계에서 테스트한다.
