# 길드 연금 작업대 GUI 작업 기록

## 현재 상태

- 사용자가 제공한 시안을 바탕으로 GUI 배경 이미지를 준비했다.
- 새로 설치하는 제작대는 바닥 가로 2칸, 높이 2칸(깊이 1칸)의 테스트용 모델이다. 최종 외형은 시안 1을 기준으로 추후 제작한다.
- 기존 버전에서 설치한 1블록 작업대는 그대로 유지한다. 회수해 다시 설치하면 2×2 크기를 사용한다.
- 새 작업대는 공간이 막혀 있으면 설치하지 않고, 네 부분 중 어느 부분을 부숴도 하나로 회수한다.
- 작업대 컨트롤러에 아이템 저장 6칸과 최대 4,000 mB 물 저장을 구현했다. GUI 메뉴에서 다섯 입력 슬롯과 결과 슬롯, 플레이어 인벤토리를 조작할 수 있다.
- GUI는 물 저장량, 레시피 및 등급 선택, 필요 재료와 제작 성공 확률을 표시한다. 서버에서 재료를 확인한 뒤 1회마다 독립적으로 성공 여부를 판정한다.
- 기본 성공 확률은 일반 100%, 고급 90%, 희귀 75%, 영웅 55%이며 서버 설정에서 조정할 수 있다.
- 성공하면 필요한 재료와 물을 소비하고 물약 한 개를 생성한다. 실패하면 보조 약초 두 종류와 촉매, 물만 소비하고 주재료와 빈 병은 그대로 남는다. 기존 결과 칸도 바뀌지 않는다.
- 각 시도는 설정된 250 mB(초기값)를 소비한다. 재료 부족이나 출력 칸 문제로 시도 자체가 거절되면 판정이나 소비는 하지 않는다.
- 원본 이미지를 보존하고 GUI의 가장자리에서 바깥 배경에 연결된 어두운 픽셀만 투명하게 렌더링한다. 실제 게임 해상도에서 확인이 필요하다.
- 물 양동이로 작업대 어느 부분이든 우클릭하면 빈 공간이 충분할 때 1,000 mB를 충전한다. 생존 모드는 빈 양동이를 돌려주고 크리에이티브 모드는 물 양동이를 유지한다.
- 일반 우클릭으로 GUI를 열어 저장량과 슬롯을 확인한다. GUI의 물 충전 버튼은 플레이어 인벤토리에 있는 물 양동이를 사용한다.
- 작업대가 파괴되면 아이템은 한 번씩 떨어지고 저장된 물은 사라진다. 주변 클라이언트에는 물 저장량만 동기화한다.

## 확정된 사항

- 물탱크 최대 용량은 **4,000 mB**다.
- 재료 입력 슬롯은 약초 3개, 촉매 1개, 빈 유리병 1개이며 결과 슬롯은 1개다.
- 플레이어 인벤토리 27칸과 핫바 9칸을 실제 메뉴 슬롯으로 연결한다.
- 물과 빈 유리병은 각각 별도의 재료로 처리한다.
- 레시피와 등급에 따라 필요한 아이템과 개수를 보여 준다.
- 저장량, 포션 미리보기와 실제 결과는 서버 데이터와 구분해 표시한다.

## 디자인 리소스

- 배경: `src/main/resources/assets/farmrpgjobs/textures/gui/guild_alchemy_background.png`
- 크기: 1536 × 1024 픽셀
- 그림 속 고정된 재료와 물의 양을 제거하고 글자, 실제 아이템, 인벤토리 36칸, 물 높이와 선택 상태를 별도로 표시한다.
- 배경 자체에 미리 선택된 레시피가 없어야 한다.
- 36칸에 맞게 아래 공간을 넓혔다. 화면 해상도와 게임의 GUI 크기에 맞는 배치 및 마우스 좌표는 실제 게임에서 검증해야 한다.

## 추후 결정·구현 사항

- 물 양동이 충전은 바닐라 양동이 용량인 1,000 mB를 사용한다. 포션 제작당 물 사용량은 제안값인 250 mB를 시험 기본값으로 사용하며 서버 설정에서 변경할 수 있다.
- 포션별 약초 수량과 등급별 촉매 수량도 서버 설정에서 변경할 수 있다. 약초 및 촉매 종류, 빈 병 1개 규칙은 유지한다.
- 최종 시안에 맞춰 제작대의 세부 모델과 텍스처를 개선한다. 현재 2×2 모델은 테스트용이다.
- 달빛의 물약은 제작할 수 있지만 현재 마나 시스템이 없어 마나 회복에 사용할 수 없다.
- 실제 게임과 멀티플레이에서 재료 부족, 출력 칸, 파괴, 서버 재시작 등을 테스트한다.
